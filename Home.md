## 📘 Описание проекта

KnowNet — сервис для работы с метриками, организационными данными и пользовательскими рабочими пространствами. Проект состоит из двух основных частей:

* **Frontend (React/TypeScript)** — визуальный интерфейс, управление состоянием, UI‑компоненты, интеграция с API.
* **Backend (NestJS)** — API, работа с базой данных, авторизация, обработка ошибок.

Документация разделена на соответствующие модули.
